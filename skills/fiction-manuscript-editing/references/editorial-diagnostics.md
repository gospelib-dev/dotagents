# Editorial diagnostics

## Reverse-outline worksheet

For every scene, record:

| Scene | POV | Entry state | Immediate goal | Opposition | Choice | Turn | Exit state | Function | Outline beat |
|---|---|---|---|---|---|---|---|---|---|

Then ask:

1. If the scene vanished, which later event, choice, relationship, or understanding would fail?
2. Is the function dramatic, or only informational?
3. Does the scene change the character's value/knowledge/plan, as McKee's turn test requires [S13]?
4. Is the turn caused by prior setup and character action?
5. Does the exit state create a specific next pressure?

## Causal-chain test

Write the major sequence as:

`setup → pressure → perception → choice → action → result → reaction → next goal`

A gap names the likely edit:

- missing setup: plant evidence earlier;
- missing pressure: make the cost of inaction present;
- missing choice: restore character agency;
- missing mechanism: clarify how action produced result;
- missing reaction: add only the smallest beat needed to register meaning;
- missing next goal: sharpen scene exit.

Do not add explanation if staging can make the link visible.

## Scene-load map

Label each paragraph or beat:

- `A` action
- `D` dialogue
- `R` reflection/reaction
- `S` setting/sensory
- `E` exposition
- `T` transition

Look for:

- long single-mode runs that stop changing state;
- dialogue without physical or relational movement;
- action without orientation or consequence;
- exposition that duplicates inference;
- reflection that repeats the just-dramatized feeling;
- transitions longer than the event they bridge.

A run is evidence, not proof. Quiet and sustained modes can be intentional.

## Finding quality test

A required finding passes only if it contains:

1. a named class;
2. exact file:line and quotation;
3. every other instance in scope;
4. observable reader effect;
5. the governing project/craft reason;
6. a bounded revision target rather than a ghostwritten replacement;
7. an acceptance test that closes the class.

Example:

> **Major — repeated decision beat — chNN:40.** The scene decides to leave here, then re-decides at chNN:61 and chNN:74 without new cost or information. The repetitions flatten escalation. Keep the first decision, make the later beats test or complicate it, and preserve the final irreversible action. **Acceptance:** one decision, later beats change pressure or consequence, no loss of required outline beats.

## Severity calibration

- **Blocker:** a reader cannot form the intended causal/POV/continuity model, or a binding rule is broken.
- **Major:** the model is intelligible but the scene fails its intended turn, agency, tension, or emotional function.
- **Minor:** the scene works; a bounded clarity, rhythm, or copy fault remains.
- **Suggestion:** a plausible alternative with no objective failure.

If two readers could reasonably prefer either version and no project rule resolves it, it is not required.

## Revision order

1. owner decision or canon conflict;
2. binding guardrail;
3. causality and required plot beat;
4. motivation, agency, knowledge, relationship;
5. scene purpose and pacing;
6. paragraph clarity and rhythm;
7. sentence mechanics and style sheet;
8. proofing.

This order prevents polishing material that structural work will replace [S1, S2].
