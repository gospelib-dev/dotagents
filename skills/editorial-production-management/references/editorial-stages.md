# Editorial stages in depth

## Definitions (Editorial Freelancers Association [S1])
- **Developmental editing** (also substantive, structural, content): content, organization, genre. Output is a
  manuscript evaluation (critique: describes problems) or a revision/edit letter (outlines big-picture issues and
  suggests fixes). The terms overlap and are used interchangeably [S1][S3].
- **Line editing**: sentence/paragraph level; corrects errors like a copyeditor but focuses on language and
  style. Done separately, after developmental, or combined with copyediting [S1].
- **Copyediting**: spelling, grammar, usage, punctuation, cross-references; prepares the **style sheet** for
  consistency [S1]. Ranges from light (query the author) to heavy (revise the text) [S1].
- **Proofreading**: final check for typos and typesetting problems (running heads, page makeup, ebook flow);
  compares the latest proof with the previous stage. Not considered editing; comes after full editing [S1].
- **Project management / managing editor / production editor**: pushes a project already in production to
  completion; coordinates and hires copyeditors, proofreaders [S1]. This is the production manager's lane.

## Order and why
The Friedman-hosted editor guide gives the continuum developmental -> substantive -> copy -> proofread and advises
different people for different levels [S4]. Copyeditors "will not fix the big-picture things like structure,
pacing, theme, or plot" [S4]. Proofreaders at PDF stage look for bad breaks, hyphen stacks, widows and orphans,
header/footer and TOC page mismatches, and should be a fresh set of eyes [S2].

## Trade production sequence (for calibration)
Penguin Random House: copyedit -> text designer check -> compositor produces "first pass"/galleys -> freelance
proofreader + author + designer review -> collated corrections -> second pass [S15]. Cornell University Press:
~4 weeks for copyedit, 3-4 weeks for author review, and no non-typo changes in proofs [S12]. Galleys (ARCs)
are made from first-pass proofs [S25].

## Self-publishing sequence (Friedman checklist [S19])
Editing (formal copyedit; ~2 weeks for 80k words; book a month ahead; 1-2 weeks author review) -> design ->
proofing (a formal proofread is advised if the copyedit was skipped or only one person has seen the files).

## Readers outside the team
- Beta reader types (Friedman [S5]): (1) target-audience readers report what they liked, what didn't work,
  whether they'd buy; not editors; (2) sensitivity readers and subject-matter experts, always paid; (3) writing
  friends, best after several drafts. Before agreeing, a beta reader should get a one-page synopsis and a
  deadline [S5].
- Sensitivity/authenticity reads: line notes plus a written analysis is a typical deliverable; not copyeditors;
  author stays responsible [S6]. Not a shield or permission; communities are not monolithic; engage before
  changes become impossible; standard rates usually cover one round [S7]. Don't expect sign-off; don't ask
  unpaid community members [S8].
- Disability tropes named by Disability in Kidlit contributors: disabled saint / inspiration, disabled villain,
  magical cure, "damaged/broken" disabled person [S9]. Risk points to look for: narration or dialogue that
  labels disabled characters as broken; climaxes where a disability is removed (frame as choice and cost, not
  cure or loss of worth). A character deliberately written as saintly is not automatically a disability trope
  unless the character is disabled.

## Stage-to-lane mapping template
| Stage | Lane | Gate artifact |
|---|---|---|
| Developmental assessment | editor (+ specialists) | per-chapter assessment |
| Developmental revision | author, reviewed by editor | PR per seam group |
| Owner structural read | owner | recorded sign-off |
| Line | author + voice/pacing reviewers | contiguous batch PRs |
| Copyedit | language reviewer + copyedit pass; style sheet | style sheet file + zero open queries |
| Proof | fresh reviewer, other model family from whoever typeset | proof checklist |
